# AI 운영 도우미 — 화면 프로토타입

AiWACS 실제 제품을 살펴보고, "판정 이후(해석·결정·조치·학습)"의 공백을 AI로 채운다는 컨셉으로 만든 **화면·흐름 프로토타입**이다. 발표·기획 검토용이며, AI 응답은 실제 Gemini 호출이 아닌 **데모 시나리오**다.

## 여는 법
`ai-assistant-prototype.html` 파일을 브라우저로 그냥 열면 된다. (단일 파일, 서버 불필요)
> 운영 중인 앱에서 함께 서빙하고 싶으면 `../aiwacs/src/main/resources/static/` 로 옮기면 `/ai-assistant-prototype.html` 로 접속된다.

## 넣은 AI 기능 (좌측 "AI 운영 도우미")
| 기능 | 해결하는 운영 병목 |
|------|--------------------|
| **운영 브리핑** | 전 서버를 한 번에 요약 + 위험순 우선순위 조치 (알림 피로·상황 파악) |
| **원인 추적** | 지표·프로세스·세션·로그·경로변경을 자동 결합 → 원인 사슬 (탭 순회 → 1클릭, MTTR 단축) |
| **처리내역 초안** | 알림 해제 시 AI가 처리 내용 초안 작성 → 승인만. 노하우가 쌓이는 지식 플라이휠 |
| **정책 튜닝 추천** | 실측 이력 vs 임계치 비교로 오탐/미탐 정책 탐지·조정 제안 |
| **서술형 보고서** | 차트·엑셀 대신 "무슨 일이 있었나"를 문장으로. 교대 인수인계 |
| **자연어 질의** | 필터 많은 조회 화면을 말로 → 조회 조건 변환·실행 |

## 설계 원칙 (본체와 동일)
- **판정·집계는 코드**, 해석·우선순위·조치·초안은 **AI**
- **AI는 시스템을 직접 바꾸지 않음** — 제안만, 실제 적용은 담당자 확인 후 코드가 검증
